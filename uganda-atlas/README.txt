Uganda Wikimedia Atlas (offline copy)

1. Unzip this folder.
2. Windows: double-click start-windows.bat. Mac/Linux: run start-mac-linux.sh.
3. Your browser opens http://localhost:8000. Keep the black window open while you use it.

Needs Python 3 (python.org). Double-clicking index.html will not work because browsers block local data files.
No internet needed.
